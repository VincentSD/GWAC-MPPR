Lab 0: Introduction to Version Control (Git)

What is Git?

Git is a distributed version control system that allows multiple developers to work on a project simultaneously without interfering with each other's changes. It tracks changes in source code during software development, helping teams collaborate efficiently.

Git is the most popular and widely used version control system today, created by Linus Torvalds in 2005 for the development of the Linux kernel.

Why Use Git?

  • Version Control: Keep track of changes and revert to previous versions if necessary.
  • Collaboration: Facilitate teamwork by merging changes from different contributors.
  • Branching: Experiment with new features in isolated branches without affecting the main codebase.
  • Backup: Keep your code safe on remote repositories like GitHub or GitLab.
  • History: Maintain a complete history of all changes with detailed commit messages.
  • Distributed: Work offline and sync when connected to the network.

Key Concepts

Repository

A directory that contains your project and the entire history of changes.

Commit

A snapshot of your project at a specific point in time.

Branch

A separate line of development that allows you to work on features independently.

Merge

The process of combining changes from different branches.
