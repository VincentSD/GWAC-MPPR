Complex Model Structures

Beyond Simple SIR: Advanced Compartmental Models

SEIR Model

Adds an Exposed compartment for diseases with incubation periods:

S → E → I → R

Where E represents exposed (infected but not yet infectious) individuals.

Age-Structured Models

Separates populations by age groups with different transmission rates:

Sᵢ → Iᵢ → Rᵢ

Where i represents different age groups with age-specific parameters.

Spatial Models

Incorporates geographic spread and movement between locations:

Sⱼ → Iⱼ → Rⱼ

Where j represents different spatial locations with migration terms.

Advanced SIR with Age Structure

Let's implement a more realistic age-structured SIR model:

Age-structured SIR model 
# Age-structured SIR model with odin
age_sir_model <- odin({
  # Age groups: 0-19, 20-59, 60+
  n_age <- 3
  
  # Initial conditions for each age group
  initial(S[1:n_age]) <- S0[1:n_age]
  initial(I[1:n_age]) <- I0[1:n_age]
  initial(R[1:n_age]) <- R0[1:n_age]
  
  # Parameters
  S0[1:n_age] <- user()
  I0[1:n_age] <- user()
  R0[1:n_age] <- user()
  
  # Age-specific transmission rates
  beta[1:n_age] <- user()
  
  # Age-specific recovery rates
  gamma[1:n_age] <- user()
  
  # Contact matrix between age groups
  contact_matrix[1:n_age, 1:n_age] <- user()
  
  # Total population in each age group
  N[1:n_age] <- S[i] + I[i] + R[i]
  
  # Force of infection for each age group
  lambda[1:n_age] <- sum(contact_matrix[i, 1:n_age] * I[1:n_age] * beta[1:n_age] / N[1:n_age])
  
  # Derivatives
  deriv(S[1:n_age]) <- -lambda[i] * S[i]
  deriv(I[1:n_age]) <- lambda[i] * S[i] - gamma[i] * I[i]
  deriv(R[1:n_age]) <- gamma[i] * I[i]
  
  # Outputs
  output(total_infected) <- sum(I[1:n_age])
  output(age_specific_incidence) <- lambda[i] * S[i]
})

Uncertainty Quantification

Why Uncertainty Matters

All models have uncertainty due to:

  • Parameter uncertainty: We don't know exact values
  • Model uncertainty: Our model may be wrong
  • Data uncertainty: Observations have errors
  • Structural uncertainty: Missing mechanisms

Methods for Quantifying Uncertainty

Monte Carlo Sampling

Sample parameters from probability distributions and run many simulations:

# Monte Carlo uncertainty analysis
n_simulations <- 1000
uncertainty_results <- matrix(0, n_simulations, 3)

for (i in 1:n_simulations) {
  # Sample parameters from distributions
  beta_sample <- rnorm(1, mean = 0.3, sd = 0.05)
  gamma_sample <- rnorm(1, mean = 0.1, sd = 0.02)
  
  # Run model
  result <- run_sir_model(beta_sample, gamma_sample)
  uncertainty_results[i, ] <- c(beta_sample, gamma_sample, max(result$I))
}

# Analyze results
quantile(uncertainty_results[, 3], c(0.025, 0.5, 0.975))

Profile Likelihood

Explore how the likelihood changes as parameters vary:

# Profile likelihood for beta
beta_range <- seq(0.1, 0.5, by = 0.01)
profile_likelihood <- numeric(length(beta_range))

for (i in 1:length(beta_range)) {
  # Fix beta, optimize gamma
  profile_likelihood[i] <- optimize_gamma_given_beta(beta_range[i], data)
}

# Plot profile likelihood
plot(beta_range, profile_likelihood, type = "l")

Bootstrap Methods

Resample data to estimate parameter uncertainty:

# Bootstrap parameter estimation
n_bootstrap <- 1000
bootstrap_params <- matrix(0, n_bootstrap, 2)

for (i in 1:n_bootstrap) {
  # Resample data with replacement
  bootstrap_data <- data[sample(nrow(data), replace = TRUE), ]
  
  # Fit model to bootstrap sample
  fit <- fit_sir_model(bootstrap_data)
  bootstrap_params[i, ] <- fit$par
}

# Calculate confidence intervals
apply(bootstrap_params, 2, quantile, c(0.025, 0.975))

COVID-19 Modeling at Imperial College London

Report 9: Impact of Non-Pharmaceutical Interventions

This landmark study used age-structured SEIR models to predict the impact of social distancing measures:

Key Findings

  • With interventions: 20,000 deaths in UK
  • Peak healthcare demand: 8x current capacity
  • Intervention duration: 12-18 months

Model Comparison and Selection

How to Choose the Right Model

Model Complexity vs. Data

More complex models require more data to estimate parameters reliably:

  • Simple SIR: Good for limited data, basic insights
  • Age-structured: Better fit, but needs age-specific data
  • Spatial models: Most realistic, but data-intensive

Information Criteria

Use statistical measures to compare models:

# Calculate AIC and BIC for model comparison
aic_values <- c(
  simple_sir = AIC(simple_fit),
  age_structured = AIC(age_fit),
  spatial_model = AIC(spatial_fit)
)

bic_values <- c(
  simple_sir = BIC(simple_fit),
  age_structured = BIC(age_fit),
  spatial_model = BIC(spatial_fit)
)

# Lower values are better
best_aic <- names(which.min(aic_values))
best_bic <- names(which.min(bic_values))

Out-of-Sample Validation

Test models on data they weren't fitted to:

# Split data into training and validation sets
set.seed(123)
train_indices <- sample(1:nrow(data), 0.7 * nrow(data))
train_data <- data[train_indices, ]
validation_data <- data[-train_indices, ]

# Fit models to training data
train_fits <- list(
  simple = fit_simple_sir(train_data),
  age = fit_age_sir(train_data),
  spatial = fit_spatial_sir(train_data)
)

# Evaluate on validation data
validation_errors <- sapply(train_fits, function(fit) {
  mean((predict(fit, validation_data) - validation_data$cases)^2)
})
