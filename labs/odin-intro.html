Introduction to odin

Building epidemiological models using the powerful odin package for model specification

⏱️ 1.5 hours 📚 Intermediate 🔬 Modeling

What is odin?

Model Specification Language

odin is a domain-specific language for specifying mathematical models, particularly differential equation models used in epidemiology, ecology, and other dynamic systems.

Key Features

  • Declarative model specification
  • Automatic code generation
  • Efficient C++ compilation
  • Integration with R workflows
  • Support for complex model structures

Why Use odin?

  • Models are easier to read and understand
  • Automatic handling of technical details
  • Better performance than pure R implementations
  • Easier to maintain and modify
  • Built-in validation and error checking

Real-World Example: Imperial College COVID-19 Models

The Imperial College London team used odin extensively for their COVID-19 modeling work:

  • Age-structured transmission models
  • Multi-compartment SEIR models
  • Healthcare capacity models
  • Vaccination impact models
  • Policy intervention scenarios

Your First odin Model: SIR

The SIR Model

The Susceptible-Infected-Recovered (SIR) model is the foundation of infectious disease modeling. It tracks three populations over time:

S (Susceptible)

People who can become infected

I (Infected)

People who are currently infected and can spread the disease

R (Recovered)

People who have recovered and are immune

Mathematical Equations

The SIR model is described by these differential equations:

Rate of Change in Susceptible Population

dS/dt = -β × S × I / N

Susceptible people become infected at rate β (transmission rate)

Rate of Change in Infected Population

dI/dt = β × S × I / N - γ × I

Infected people recover at rate γ (recovery rate)

Rate of Change in Recovered Population

dR/dt = γ × I

Recovered people accumulate as infected people recover

Key Parameters

  • β (beta): Transmission rate - how easily the disease spreads
  • γ (gamma): Recovery rate - how quickly people recover
  • N: Total population size
  • R₀: Basic reproduction number = β/γ

Building the SIR Model with odin

Step-by-Step Implementation

Step 1: Install and Load odin

Install odin package 
# Install from R-universe
install.packages("odin2", repos = c("https://mrc-ide.r-universe.dev", "https://cloud.r-project.org"))

# Load the package
library(odin2)

Step 2: Define the SIR Model

SIR model specification 
sir_model <- odin({
  # Initial conditions
  initial(S) <- N - I0 - R0
  initial(I) <- I0
  initial(R) <- R0
  
  # Parameters
  N <- user(1000)    # Total population
  I0 <- user(1)      # Initial infected
  R0 <- user(0)      # Initial recovered
  beta <- user(0.3)  # Transmission rate
  gamma <- user(0.1) # Recovery rate
  
  # Derivatives (differential equations)
  deriv(S) <- -beta * S * I / N
  deriv(I) <- beta * S * I / N - gamma * I
  deriv(R) <- gamma * I
  
  # Output variables
  output(R0_basic) <- beta / gamma
  output(incidence) <- beta * S * I / N
})

This odin code defines the complete SIR model with initial conditions, parameters, differential equations, and output variables.

Step 3: Compile and Run the Model

Compile and simulate 
# Compile the model
mod <- sir_model()

# Set time points for simulation
t <- seq(0, 100, by = 0.1)

# Run the simulation
result <- mod$run(t)

# Convert to data frame for analysis
result_df <- as.data.frame(result)

SIR Model Implementation

# SIR Model Differential Equations
# dS/dt = -β * S * I / N
# dI/dt = β * S * I / N - γ * I  
# dR/dt = γ * I

# Parameters
N <- 1000        # Total population
β <- 0.3         # Transmission rate
γ <- 0.1         # Recovery rate
I0 <- 1          # Initial infected

# Initial conditions
S0 <- N - I0     # Initial susceptible
R0 <- 0          # Initial recovered

# Time steps
time_steps <- 100
dt <- 0.1

# Arrays to store results
S <- numeric(time_steps)
I <- numeric(time_steps)
R <- numeric(time_steps)
time <- numeric(time_steps)

# Set initial values
S[1] <- S0
I[1] <- I0
R[1] <- R0
time[1] <- 0

# Euler integration
for (i in 2:time_steps) {
    # Calculate rates
    infection_rate <- β * S[i-1] * I[i-1] / N
    recovery_rate <- γ * I[i-1]
    
    # Update compartments
    S[i] <- S[i-1] - infection_rate * dt
    I[i] <- I[i-1] + infection_rate * dt - recovery_rate * dt
    R[i] <- R[i-1] + recovery_rate * dt
    
    # Ensure population conservation
    S[i] <- max(0, S[i])
    I[i] <- max(0, I[i])
    R[i] <- max(0, R[i])
    
    # Update time
    time[i] <- time[i-1] + dt
}

# Results are now in S, I, R, and time arrays

Understanding Model Outputs

Key Insights from the SIR Model

Epidemic Peak

The peak of infections occurs when the number of new infections equals the number of recoveries. This happens when S = N × γ/β.

Herd Immunity

Herd immunity is reached when enough people are immune (recovered) that the disease can no longer spread effectively.

R₀ and Epidemic Dynamics

  • R₀ > 1: Epidemic grows
  • R₀ = 1: Endemic equilibrium
  • R₀ < 1: Epidemic declines

Parameter Sensitivity

Small changes in transmission rate (β) can have large effects on epidemic timing and size. This is why interventions like social distancing are so important.
