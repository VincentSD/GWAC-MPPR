What is monty?

Model Fitting Package

monty is an R package designed specifically for fitting odin models to data. It provides tools for parameter estimation, uncertainty quantification, and model validation.

Key Features

  • Efficient parameter estimation
  • Multiple optimization algorithms
  • Uncertainty quantification
  • Model validation tools
  • Integration with odin models
  • Parallel computing support

Why Use monty?

  • Optimized for epidemiological models
  • Handles complex model structures
  • Provides confidence intervals
  • Fast computation with C++ backend
  • Easy integration with existing workflows

Hands-on Exercise: Fitting SIR Model to COVID-19 Data

Exercise: Estimate Transmission and Recovery Rates

In this exercise, you'll fit an SIR model to simulated COVID-19 case data to estimate the transmission rate (β) and recovery rate (γ).

Setup

Install required packages 
# Install monty and other required packages
install.packages(
  c("monty", "odin2"),
  repos = c("https://mrc-ide.r-universe.dev", "https://cloud.r-project.org")
)

# Load packages
library(monty)
library(odin2)
library(tidyverse)

Step 1: Generate Simulated Data

First, let's create some realistic COVID-19 case data to fit our model to:

Generate simulated data 
# True parameters (we'll try to estimate these)
true_beta <- 0.3
true_gamma <- 0.1
N <- 10000
I0 <- 100

# Generate data with some noise
set.seed(123)
t <- seq(0, 100, by = 1)

# Run SIR model
sir_model <- odin({
  initial(S) <- N - I0
  initial(I) <- I0
  initial(R) <- 0
  
  deriv(S) <- -beta * S * I / N
  deriv(I) <- beta * S * I / N - gamma * I
  deriv(R) <- gamma * I
  
  beta <- user(0.3)
  gamma <- user(0.1)
  N <- user(10000)
})

mod <- sir_model()
result <- mod$run(t)
result_df <- as.data.frame(result)

# Add noise to simulate real data
set.seed(456)
observed_cases <- result_df$I + rnorm(length(t), 0, 50)
observed_cases <- pmax(observed_cases, 0)  # Ensure non-negative

# Create data frame for fitting
data_for_fitting <- data.frame(
  time = t,
  cases = observed_cases
)

# Plot the data
ggplot(data_for_fitting, aes(x = time, y = cases)) +
  geom_point(color = "red", alpha = 0.7) +
  geom_line(data = result_df, aes(y = I), color = "blue", size = 1) +
  labs(
    title = "Simulated COVID-19 Cases",
    subtitle = "Red points: Observed data, Blue line: True model",
    x = "Time (days)",
    y = "Number of cases"
  ) +
  theme_minimal()

Step 2: Define the Fitting Model

Now let's create an odin model that we can fit to the data:

Define fitting model 
# Define the model for fitting
fitting_model <- odin({
  initial(S) <- N - I0
  initial(I) <- I0
  initial(R) <- 0
  
  deriv(S) <- -beta * S * I / N
  deriv(I) <- beta * S * I / N - gamma * I
  deriv(R) <- gamma * I
  
  # Parameters to estimate
  beta <- user(0.3)
  gamma <- user(0.1)
  
  # Fixed parameters
  N <- user(10000)
  I0 <- user(100)
  
  # Output for fitting
  output(incidence) <- beta * S * I / N
})

Step 3: Define the Objective Function

We need to define how well our model fits the data:

Define objective function 
# Objective function for fitting
objective_function <- function(pars, data, model) {
  # Extract parameters
  beta <- pars[1]
  gamma <- pars[2]
  
  # Set model parameters
  model$set_user(beta = beta, gamma = gamma)
  
  # Run model
  result <- model$run(data$time)
  result_df <- as.data.frame(result)
  
  # Calculate sum of squared errors
  predicted <- result_df$I
  observed <- data$cases
  
  # Use log-likelihood for better numerical properties
  sigma <- 50  # Standard deviation of noise
  log_likelihood <- sum(dnorm(observed, predicted, sigma, log = TRUE))
  
  # Return negative log-likelihood (for minimization)
  return(-log_likelihood)
}

Step 4: Fit the Model with monty

Now let's use monty to find the optimal parameters:

Fit model with monty 
# Compile the model
mod <- fitting_model()

# Initial parameter values
initial_params <- c(beta = 0.2, gamma = 0.15)

# Parameter bounds
lower_bounds <- c(beta = 0.01, gamma = 0.01)
upper_bounds <- c(beta = 1.0, gamma = 0.5)

# Fit the model using monty
fit_result <- monty::optimize_model(
  objective_function,
  initial_params,
  data = data_for_fitting,
  model = mod,
  lower = lower_bounds,
  upper = upper_bounds,
  method = "L-BFGS-B"
)

# Extract results
best_params <- fit_result$par
best_value <- fit_result$value

cat("Fitting completed!\n")
cat("Best parameters:\n")
cat("  beta (transmission rate):", round(best_params[1], 4), "\n")
cat("  gamma (recovery rate):", round(best_params[2], 4), "\n")
cat("  Objective value:", round(best_value, 2), "\n")

# Compare with true values
cat("\nTrue parameters:\n")
cat("  beta:", true_beta, "\n")
cat("  gamma:", true_gamma, "\n")

Model Validation and Diagnostics

Assessing Model Fit

Residual Analysis

Examine the differences between observed and predicted values:

  • Patterns: Look for systematic deviations
  • Distribution: Residuals should be normally distributed
  • Heteroscedasticity: Check for changing variance

Goodness of Fit Metrics

  • R²: Proportion of variance explained
  • RMSE: Root mean square error
  • AIC/BIC: Model comparison criteria
  • Likelihood ratio tests: Nested model comparison

Parameter Uncertainty

  • Confidence intervals: Range of plausible values
  • Correlation matrix: Parameter dependencies
  • Profile likelihoods: Individual parameter uncertainty
  • Bootstrap methods: Non-parametric uncertainty
