# Models Directory

This directory contains the disease modeling implementations for the collaborative project.

## 📋 Model Assignments

### Person A: Basic SIR Model
- Implement a basic Susceptible-Infected-Recovered model
- Include parameter validation
- Add visualization functions
- Create example usage

### Person B: SEIR Model  
- Extend SIR to include Exposed compartment
- Handle incubation period
- Add parameter sensitivity analysis
- Include comparison with SIR

### Person C: Age-Structured Model
- Implement age-dependent transmission rates
- Include demographic data handling
- Add age-specific interventions
- Create visualization by age group

### Person D: Model Fitting & Validation
- Implement parameter estimation
- Add goodness-of-fit measures
- Include cross-validation
- Create model comparison tools

## 🚀 Getting Started
1. Create a new branch: `git checkout -b feature/your-model-name`
2. Implement your assigned model in a new R file
3. Add tests and documentation
4. Submit a pull request

## 📝 File Naming Convention
- `sir_model.R` - Basic SIR implementation
- `seir_model.R` - SEIR with exposed compartment
- `age_structured_model.R` - Age-dependent transmission
- `model_validation.R` - Fitting and validation tools
