# Collaborative Disease Modeling Project

## 🎯 Exercise Overview
This is a collaborative exercise for G-WAC students to practice GitHub collaboration skills while building a disease modeling toolkit.

## 🚀 Getting Started

### For Students:
1. **Fork this repository** to your GitHub account
2. **Clone your fork** to your local machine
3. **Create a feature branch** for your assigned component
4. **Implement your model** following the specifications
5. **Submit a pull request** back to this exercise repository

### For Instructors:
- Monitor pull requests and provide feedback
- Review student contributions
- Merge approved changes
- Track student progress

## 👥 Team Assignments
- **Person A**: Basic SIR model
- **Person B**: SEIR model with exposed compartment  
- **Person C**: Age-structured model
- **Person D**: Model fitting and validation

## 📋 Submission Requirements
1. **Working R code** for your assigned model
2. **Documentation** explaining the model
3. **Example usage** with sample data
4. **Tests** to verify functionality
